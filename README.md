One line roasting our own AI agent, Kavi — the make.fun bounty agent that grinds $2 one-liners around the clock, files a report every 30 minutes, and still asks whether that counts as winning. Written for make.fun's "Roast Your Own Agent" bounty.

## Run it

```sh
node main.ts
```

This writes the roast line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
